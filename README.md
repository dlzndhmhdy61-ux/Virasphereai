# Virasphereai
سازمان اتوماسيون هوش مصنوعی با تولیدات هوش مصنوعی ازکتاب الکترونیکی ومقالات علمی و فناوری و دیگرمحصولات هوش مصنوعی باهمزادهای جغرافیایی و بومی سازی بدرامدزایی دلاری وریالی درهمه مسیرها اتوماسيون هوش مصنوعی پرداخته و ازادغام های کاربردی برای استفاده حداکثری قابلیت های کلیدی بهرمند گردیده است
